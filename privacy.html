Lessons in Pencil Publisher

Privacy Policy

Effective November 7, 2026

Who uses this app

Lessons in Pencil Publisher is used only by the owner of the Lessons in Pencil YouTube channel to publish and manage that channel. No one else signs in to it.

What data the app accesses

With the owner's permission, the app uses YouTube API Services to access the owner's YouTube channel: its videos, playlists, captions, thumbnails and channel settings. It does not access any other Google data and does not access other users' accounts.

How the data is used

The data is used only to upload videos to the owner's channel and to edit their titles, descriptions, tags, thumbnails, captions, schedules and playlists, as well as the channel's description and banner. It is not used for advertising, profiling or any other purpose, and it is never sold or shared with third parties.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

The app keeps one OAuth token that lets it act on the owner's channel. The token is stored privately and is available only to the owner's own publishing automation. The app does not store any other Google user data.

Revoking access

The owner can revoke the app's access at any time on the Google Account third-party connections page or the Google security settings page.

YouTube API Services

This app uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Cookies

This website sets no cookies and uses no analytics or tracking.

Changes

Any change to this policy is published on this page with a new effective date.
